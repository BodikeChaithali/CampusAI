# **App Name**: CampusAI

## Core Features:

- PDF Upload: Allows users to upload PDF documents containing campus information.
- Text Extraction: Extracts text from uploaded PDFs for processing by the AI.
- AI Question Answering: Uses the Google Gemini API to answer questions based solely on the content of the uploaded PDFs. The prompt includes the rule: "Answer the question using ONLY the information from the provided PDF content. If the answer is not present, respond with: 'The information is not available in the document.'" The AI is used as a tool.
- Concise Answer Display: Displays the AI's answers in a clear and easily readable format.

## Style Guidelines:

- Primary color: Dark purple (#6750A4) for a scholarly and modern feel.
- Background color: Very light purple (#F2F0FA).
- Accent color: Deep pink (#E44CAF) for highlights and calls to action.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Use simple, academic-themed icons.
- Clean and organized layout with a focus on readability.
- Subtle animations for loading and transitions.
