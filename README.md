# CampusAI 📄🤖

CampusAI is an AI-powered web application that allows users to upload PDF documents and receive clear, text-based explanations of the content.  
It is designed to help students and learners quickly understand complex academic or technical PDFs using Google AI technologies.

---

## 🚀 Project Overview

CampusAI simplifies the process of understanding lengthy or complex PDF documents.  
Users upload a PDF, and the system analyzes its content to generate an easy-to-understand explanation while preserving the original meaning.

⚠️ **Note:**  
The application generates **text-only explanations** and does **not use or generate AI images**.

---

## ✨ Key Features

- 📤 Upload PDF documents securely  
- 🧠 AI-generated explanations from PDF content  
- 📝 Simple, structured, and readable text output  
- 🔒 Secure authentication and backend services  
- ⚡ Fast and responsive user interface  
- ☁️ Cloud-based and scalable architecture  

---

## 🛠️ Technology Stack

### Frontend
- **Next.js** (React-based framework)
- **TypeScript**
- **Tailwind CSS**

### Backend & Cloud
- **Firebase Authentication**
- **Firestore Database**
- **Firebase Cloud Functions**
- **Firebase Hosting**

### AI & Google Technologies
- **Gemini API** (for PDF content understanding and explanation)
- **Google Cloud Platform (GCP)**
- **Firebase Studio**

---

## 🏗️ System Architecture

1. User uploads a PDF document  
2. Next.js frontend sends the file for processing  
3. Firebase Cloud Functions handle the request  
4. Gemini API analyzes the PDF content  
5. Text-based explanation is generated  
6. Result is displayed to the user
